# 课游工坊

> 让每个老师都能 5 分钟做出课堂互动游戏

## 这是什么

课游工坊是一款面向小学语文教师的零代码教学游戏生成工具。老师选择课本课文 → AI 出题 → 选择游戏模板 → 预览 → 下载单文件离线 HTML 游戏，直接发给学生上课用。

## 使用方式

### 教师（直接用）

**双击启动器**：
- macOS：双击 `启动课游工坊.command`
- Windows：双击 `启动课游工坊.bat`

浏览器会自动打开，无需安装任何软件。

启动器的三级回退策略：
1. 先找 Python（macOS 自带，Windows 可能需安装）
2. 再用 PowerShell 启动服务（所有 Windows 自带，无需安装任何东西）
3. 最后直接用浏览器打开 HTML 文件

**使用流程**：
1. 选择年级 → 学期 → 单元 → 课文
2. 粘贴课文内容
3. 选择题型、难度、数量 → 点击「生成题目」
4. AI 出题后可逐题编辑
5. 选择游戏模板（闯关问答 / 连连看 / 翻牌记忆）
6. 预览效果 → 下载 HTML 文件
7. 双击下载的 HTML 文件即可在浏览器中玩游戏（完全离线）

> 首次使用需在输入面板填入 DeepSeek API Key（存储在浏览器本地）

### 开发者（改代码）

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
```

## 技术栈

- React 18 + Vite + TypeScript + TailwindCSS
- Zustand（状态管理）
- DeepSeek V4 flash（AI 出题）
- 原生 HTML/CSS/JS（游戏模板，零依赖）

## 功能特点

- **AI 智能出题**：基于课本内容定向出题，不跑偏
- **三种游戏**：闯关问答、连连看、翻牌记忆
- **单文件离线导出**：零依赖 HTML，断网可用
- **防作弊**：答案不暴露在 DOM 中
- **课本锚定**：部编版小学语文 1-6 年级课文目录
- **双击即用**：启动器一键打开，无需装环境
