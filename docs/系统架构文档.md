│  └─────┬────┘ └─────┬────┘ └──────────────┘       │
│        │            │                               │
│  ┌─────▼────────────▼──────────────┐                │

│  └───────────────────┬────────────┘                │
│                      │                              │

## 模块说明

### 1. 教师工作台 (`src/components/teacher/`)
React 单页应用，5 步流程：输入配置 → 题目编辑 → 选择游戏 → 预览 → 导出。
使用 Zustand 管理全局状态（`src/store/useAppStore.ts`）。

### 2. AI 出题模块 (`src/engine/ai/`)
- **prompts/**：提示词配置，按学科分文件。模板变量用 `{{var}}` 语法。
- **provider.ts**：DeepSeek API 抽象层。实现 `AIProvider` 接口，API key 从 localStorage 读取。
- **generator.ts**：出题服务。组装提示词 → 调用 API → 解析结果 → 校验去重。
- **parser.ts**：AI 返回结果解析。从文本中提取 JSON，解析为 Question[] 或 MatchPair[]。

### 3. 规则解析引擎 (`src/engine/parser/`)
AI 不可用时的降级方案。解析老师手动粘贴的文本，识别选择题/判断题/配对题。

### 4. 游戏模板 (`src/games/`)
插件化架构。每个游戏实现 `GameTemplate` 接口，注册到 `gameRegistry`。
三个内置游戏：
- 闯关问答 (`quiz/`)：选择题、判断题
- 连连看 (`matching/`)：配对题
- 翻牌记忆 (`memory/`)：记忆配对

### 5. 导出引擎 (`src/engine/exporter/`)
调用游戏模板的 `generateHTML()` 方法，生成单文件 HTML，通过 Blob 下载。

### 6. 安全模块 (`src/engine/security/`)
- **escape.ts**：HTML 转义，防 XSS
- **scan.ts**：敏感信息扫描（手机号/身份证/密钥）
- **encode.ts**：Base64 编解码，答案不暴露在 DOM 中

### 7. 课本目录 (`src/data/textbooks.ts`)
部编版小学语文 1-6 年级课文目录。老师选择年级→学期→单元→课文。

## 数据流

1. 老师选择：学科 → 年级 → 学期 → 单元 → 课文
2. 老师粘贴课文内容
3. 老师选择：知识点 → 题型 → 难度 → 数量
4. 点击「生成题目」
5. AI 模块组装提示词 → 调用 DeepSeek API → 返回文本
6. parser 解析 JSON → 生成 Question[] / MatchPair[]
7. 存入 Zustand store → 显示在编辑面板
8. 老师编辑/删除/添加题目
9. 选择游戏模板 → 预览（iframe 渲染）
10. 导出 → generateHTML() → Blob 下载

## 技术选型理由

| 选型 | 理由 |
|------|------|
| React 18 + Vite | 原方案验证可行，构建快，生态好 |
| TailwindCSS | 快速开发，原子化样式，易于调整 |
| Zustand | 轻量无 Provider 嵌套，API 直觉友好 |
| 原生 HTML/CSS/JS（游戏） | 零依赖是硬要求，导出的游戏必须断网可用 |
| DeepSeek V4 flash | 国产 API，中文能力强，支持联网搜索 |

## 部署方式

- **教师工作台**：Vercel 静态托管，推送到 GitHub 自动部署
- **导出的游戏**：单文件 HTML，下载后双击即玩
- **无需后端**：所有逻辑在前端完成，AI API 直接从浏览器调用
