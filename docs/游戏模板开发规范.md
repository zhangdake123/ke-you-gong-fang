# 游戏模板开发规范

## 接口定义

每个游戏模板实现 `GameTemplate` 接口（定义在 `src/types/index.ts`）：

```typescript
interface GameTemplate {
  id: string;                          // 唯一标识
  name: string;                        // 显示名称
  description: string;                 // 简介
  icon: string;                        // 图标（emoji 或 SVG）
  supportedTypes: QuestionType[];      // 支持的题型
  minItems: number;                    // 最少题目数
  isRecommended: (content: GameContent) => boolean;  // 推荐判断
  generateHTML: (content: GameContent, options: ExportOptions) => string;  // 生成 HTML
}
```

## 目录结构

每个游戏模板一个文件夹：

```
src/games/my-game/
├── template.ts      # 模板定义（实现 GameTemplate 接口）
├── game.html.ts     # HTML 生成函数（返回完整 HTML 字符串）
└── (可选) helpers.ts  # 辅助函数
```

## 硬性要求

1. **零依赖**：不引入任何 CDN、框架、外部字体、外部图片
2. **单文件**：CSS 内联到 `<style>`，JS 内联到 `<script>`
3. **防作弊**：答案/配对关系不写入 DOM 属性（如 `data-answer`）
4. **数据注入**：题目数据用 Base64 编码后注入 `<script>` 标签
5. **转义**：所有用户可见文本用 `escapeHtml()` 转义
6. **响应式**：Flexbox + 三档断点（桌面/平板/手机）
7. **无障碍**：aria-live、焦点轮廓、prefers-reduced-motion

## 开发步骤

1. 复制 `src/games/quiz/` 目录结构
2. 修改 `template.ts` 中的 id/name/description/supportedTypes/minItems
3. 实现 `isRecommended()` 逻辑
4. 实现 `game.html.ts` 中的 `generateXxxHTML()` 函数
5. 在 `src/games/index.ts` 中注册新模板

## 视觉风格

- **小学生游戏**：卡通、明亮配色（蓝/绿/橙/红）、大字体、趣味动画
- 主色调参考：蓝 `#4A90D9`、绿 `#52C41A`、橙 `#FAAD14`、红 `#FF4D4F`
- 背景：浅色渐变
- 卡片：白色背景、圆角 16px、柔和阴影
- 字体：系统中文字体，大号字体
- 动画：CSS transition + keyframes
