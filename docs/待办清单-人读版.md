## 一、游戏模板扩展

### 1.1 打地鼠（高优先级）
- **路径**：`src/games/whack-mole/`
- **描述**：地鼠头顶跳出字/词，学生快速点击正确的，限时计分
- **适用场景**：低年级生字认读、词语辨析
- **设计要点**：
  - 地鼠从洞中弹出动画
  - 每只地鼠头顶显示一个词/字
  - 题目在上方显示（如"点击反义词"）
  - 正确点击加分+消除，错误点击扣分
  - 限时 60 秒
- **依赖**：选择题题型

### 1.2 诗句拼图（高优先级）
- **路径**：`src/games/poetry-puzzle/`
- **描述**：把诗句打乱，拖拽排列成正确的顺序
- **适用场景**：古诗词背诵
- **设计要点**：
  - 每句诗拆成片段
  - 拖拽排列
  - 完成后高亮显示完整诗句
  - 支持多首诗连续闯关
- **依赖**：需新增"排序题"题型

### 1.3 词语消消乐（中优先级）
- **路径**：`src/games/word-crush/`
- **描述**：方块上有词语，点击配对的消除（如"大"和"小"是反义词→消除）
- **适用场景**：近义词/反义词/同类词练习
- **设计要点**：
  - 网格布局，每格一个词
  - 点击两个词，判断关系（反义词/近义词/同类）
  - 正确则消除并加分
  - 参考消消乐游戏的消除动画

### 1.4 大转盘（中优先级）
- **路径**：`src/games/spin-wheel/`
- **描述**：转盘随机选题，答对加分，答错扣分
- **适用场景**：任意题型的复习课
- **设计要点**：
  - CSS 旋转动画的转盘
  - 转盘分成若干扇区，每个扇区一道题
  - 点击转盘旋转，停在哪里答哪题
  - 有运气成分增加趣味

### 1.5 词语接龙（低优先级）
- **路径**：`src/games/word-chain/`
- **描述**：给一个起始词，选能接上的词（尾字→首字），连续接对得分
- **适用场景**：词汇积累
- **设计要点**：
  - 给起始词，下方显示 4 个候选词
  - 选能接上的（尾字 = 候选首字）
  - 答对继续，答错结束
  - 连击加分机制

### 1.6 摘苹果（低优先级）
- **路径**：`src/games/pick-apple/`
- **描述**：树上挂满苹果（带字/拼音），点击读对的摘下来，限时摘完
- **适用场景**：一年级拼音和识字
- **设计要点**：
  - 苹果树画面，苹果上显示拼音或字
  - 题目要求（如"摘出三声的字"）
  - 点击正确苹果掉落+加分
  - 限时挑战

## 二、AI 出题增强

### 2.1 联网搜索出题（高优先级）
- **路径**：`src/engine/ai/provider.ts`
- **描述**：DeepSeek V4 flash 支持联网搜索，可搜索"这篇课文的常见练习题/考试题"
- **设计要点**：
  - 在 AIRequestOptions 中启用 webSearch
  - 提示词中加入"可参考网上权威练习题"
  - 搜索结果需标注来源
- **依赖**：DeepSeek Responses API

### 2.2 课本内容预置（高优先级）
- **路径**：`src/data/textbook-content/`
- **描述**：预置部编版常见课文的原文内容，老师不用手动粘贴
- **设计要点**：
  - 按年级/学期/单元/课文组织
  - 存储课文原文、生字表、重点词
  - 老师选择课文后自动加载内容
  - 注意版权：仅存储公开教学内容

### 2.3 智能难度调节（中优先级）
- **路径**：`src/engine/ai/generator.ts`
- **描述**：根据老师反馈（太难/太简单）自动调节下次出题难度
- **设计要点**：
  - 记录老师删除/修改的题目模式
  - 下次出题时调整提示词中的难度参数
  - 提供难度滑块（简单→困难连续调节而非三档）

### 2.4 多学科扩展（中优先级）
- **路径**：`src/engine/ai/prompts/`
- **描述**：新增数学、英语等学科的提示词配置
- **设计要点**：
  - 数学：计算题、应用题、几何题
  - 英语：单词、语法、阅读
  - 复制 chinese.ts 结构，修改知识点和提示词

### 2.5 题目质量评分（低优先级）
- **描述**：AI 出题后自动评分，标注题目质量
- **设计要点**：
  - 评分维度：准确性、难度合理性、迷惑性
  - 低分题目自动标记需人工审核

## 三、题库管理

### 3.1 题库持久化（中优先级）
- **路径**：`src/store/useBankStore.ts`
- **描述**：保存常用题库到 localStorage，支持收藏/复用
- **功能**：
  - 保存当前题目为题库条目
  - 题库列表（按时间/学科/年级筛选）
  - 一键加载题库到编辑器
  - 题库导入/导出 JSON

### 3.2 批量导入（低优先级）
- **描述**：支持从 Word/Excel 批量导入题目
- **设计要点**：
  - 解析 .docx/.xlsx 文件
  - 按格式自动识别题型
  - 批量编辑确认

## 五、部署与工程

### 5.1 Vercel 自动部署（高优先级）
- **描述**：推送到 GitHub 后自动部署到 Vercel
- **设计要点**：
  - 配置 vercel.json
  - 静态托管模式
  - 自定义域名（可选）

### 5.2 PWA 支持（中优先级）
- **描述**：教师工作台支持离线使用（PWA）
- **设计要点**：
  - Service Worker 缓存
  - manifest.json
  - 可安装到桌面

### 5.3 数据云同步（低优先级）
- **描述**：题库数据云端同步（需要后端支持）
- **设计要点**：

  - 多设备同步

## 六、游戏体验增强

### 6.1 音效系统（中优先级）
- **描述**：游戏增加音效反馈（答对/答错/翻牌/胜利）
- **设计要点**：
  - 使用 Web Audio API 生成简单音效（不引入外部音频文件）
  - 老师可在导出选项中开关音效

### 6.2 排行榜（低优先级）
- **描述**：游戏结算后可输入名字记录排行榜
- **设计要点**：
  - localStorage 存储排行榜
  - 显示 Top 10
  - 按用时/得分排序

### 6.3 多人模式（低优先级）
- **描述**：支持多人同时答题（课堂分组竞赛）
- **设计要点**：
  - 分组答题
  - 实时比分
  - 注意：需要局域网或同屏展示
