# 开发环境与构建指南

## 环境要求

- Node.js >= 18
- npm >= 9

## 本地开发

```bash
cd ke-you-gong-fang
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 构建

```bash
npm run build
```

产物在 `dist/` 目录。

## 测试

```bash
npm run test        # 运行所有测试
npm run test:watch  # 监听模式
```

## 部署

推送到 GitHub 后，Vercel 自动部署。也可手动：
```bash
npm run build
# 将 dist/ 目录部署到任意静态托管
```

## 项目结构

```
ke-you-gong-fang/
├── docs/                    # 文档（5 份）
├── src/
│   ├── components/          # React 组件
│   │   ├── teacher/         # 教师端组件
│   │   └── common/          # 通用组件
│   ├── engine/              # 核心引擎
│   │   ├── ai/              # AI 出题模块
│   │   ├── parser/          # 规则解析（降级）
│   │   ├── exporter/        # 导出引擎
│   │   └── security/        # 安全模块
│   ├── games/               # 游戏模板
│   │   ├── quiz/            # 闯关问答
│   │   ├── matching/        # 连连看
│   │   ├── memory/         # 翻牌记忆
│   │   └── shared/          # 共享工具
│   ├── store/               # Zustand 状态管理
│   ├── types/               # TypeScript 类型
│   ├── data/                # 课本目录数据
│   └── utils/               # 工具函数
├── tests/                   # 测试
├── demo-exports/            # 演示导出文件
└── package.json
```
